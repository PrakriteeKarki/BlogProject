# 📝 Blog Web Application (Django)

A simple blog web application built using **Python and Django** where users can register, create posts, and interact with posts from other users.

This project focuses on backend development concepts such as authentication, CRUD operations, and user interactions.

---

## 🚀 Features

- 🔐 User Registration, Login & Logout system  
- 📰 Feed page displaying posts from all registered users  
- ✍️ Create posts with image upload functionality  
- 📁 My Posts section to view personal posts  
- 👤 User profile page showing:
  - Name  
  - Email  
  - Date Joined  
  - User’s Posts  
- ❤️ Like system (one like per user per post)  
- 💬 Comment system (multiple comments allowed per user)

---

## 🛠️ Tech Stack

- Python  
- Django  
- Django Crispy Forms  
- HTML (basic frontend)

---

## 🏗️ Architecture

This project follows the **MVT (Model - View - Template)** architecture provided by Django.
